# Token Usage - Quick Reference

## 📊 Current Status
Get current token usage: `GET /token_usage`

**Response includes:**
- Daily usage (today)
- Hourly usage (last 60 min)
- Per-conversation usage
- Overall status indicator

---

## 🎚️ Optimization Modes

### Aggressive (Use at 80%+ usage)
```
✅ Memory consolidation batched (20K tokens saved)
✅ Post-filter disabled (1-2K saved per recall)
✅ Query caching (0.5-1K saved per cycle)
✅ Context reduced to 30% (50-100K saved per iteration)
✅ Recall interval 10x (skip 7-9 recalls)

Result: 70-80% token reduction
Cost: Smaller context window
```

### Balanced (Default - Recommended)
```
✅ Memory consolidation batched
❌ Post-filter enabled (optional based on usage)
✅ Query caching
⏸️ Context at 55% (normal operation)
⏸️ Recall interval adaptive (3-10x based on usage)

Result: 30-40% token reduction
Cost: Minimal quality impact
```

### Conservative (Full features)
```
❌ All features enabled
✅ Query caching only
⏸️ Context at 70% (full)
⏸️ Recall interval every 3 iterations

Result: <10% token reduction
Cost: None - all features work
```

## ⚙️ API Endpoints

### Check Status
```bash
curl http://localhost:50002/token_usage
```

### Get Recommendations
```bash
curl http://localhost:50002/token_usage?action=recommendations
```

### Apply Auto-Optimization
```bash
curl -X POST http://localhost:50002/token_usage?action=optimize
```

### Set Optimization Mode
```bash
curl -X POST http://localhost:50002/token_usage_config -d '{"mode":"aggressive"}'
```

### Update Limits
```bash
curl -X POST http://localhost:50002/token_usage?action=set_limit \
  -d '{"limit_type":"daily","value":1500000}'
```

## 🚀 Quick Start

### 1. Check Current Usage
```
Dashboard → External → Token Usage Management → View Usage Dashboard
OR
curl http://localhost:50002/token_usage
```

### 2. Enable Optimization
```
Settings → External → Token Usage Management
Select Mode: Balanced (Recommended)
Save
```

### 3. Monitor Usage
- Check dashboard daily
- Review recommendations
- Adjust limits if needed

### 4. If Limit Approaching
```
✓ Switch to Aggressive mode
✓ Start new conversation
✓ Disable memory features temporarily
✓ Wait for daily reset (midnight UTC)
```

## 🛡️ Prevention Tips

1. **Start conversations strategically** - Reset per-conversation limit every 50K tokens
2. **Monitor hourly** - Check usage every few hours
3. **Use balanced mode** - Better than aggressive for daily use
4. **Disable unnecessary features** - Turn off memory features if not needed
5. **Archive conversations** - Start fresh conversations for new topics

## ⚡ Emergency Actions

### If Usage at 90%+
```
1. Stop all conversations
2. Don't start new conversations
3. System will auto-block at 95%
4. Wait for daily reset (midnight UTC)
```

### If System Blocked
```
1. Check current time
2. Wait until daily reset
3. Or increase daily limit in settings
4. Or set_limit action=daily value=1500000
```

### If Memory Features Disabled
```
1. Check usage % (likely >75%)
2. Either:
   a) Continue conversation (essential features work)
   b) Start new conversation (resets per-conv limit)
   c) Use Conservative mode if under 60%
```

## 🔍 Debugging

### "Why are features disabled?"
- **Answer:** Usage >70%. Check `/token_usage` endpoint
- **Fix:** Start new conversation or switch mode

### "How much budget remains?"
- **Answer:** `GET /token_usage` shows remaining for daily/hourly
- **Display:** Dashboard shows percentage remaining

### "Can I increase limits?"
- **Answer:** Yes, use `set_limit` endpoint
- **Caution:** Increases actual Claude Max usage

### "How often does it reset?"
- **Daily:** Midnight UTC (0:00 UTC)
- **Hourly:** Every 60 minutes
- **Per-conversation:** Manual reset with new conversation
