## Memory Recall Decision Tree

```
START: Should we recall memory?
        │
        ├─ Memory recall enabled?
        │  NO → SKIP
        │  YES ↓
        │
        ├─ Usage > 85%?
        │  YES → SKIP (disabled in aggressive mode)
        │  NO ↓
        │
        ├─ Is it time? (recall_interval)
        │  Interval = 3 (normal), 5, 7, or 10 (high usage)
        │  NO → SKIP
        │  YES ↓
        │
        ├─ Is query cache valid?
        │  (check if history hash matches)
        │  YES → Use cached query (0 tokens)
        │  NO ↓
        │
        ├─ Generate new query
        │  ↓
        │  Query generation: 750 tokens
        │  ↓
        │
        ├─ Search memories
        │  ↓
        │  Embedding search: 100 tokens
        │  ↓
        │
        ├─ Apply post-filter?
        │  Usage > 70% OR disabled? → NO
        │  YES ↓
        │     Filter: 1,500 tokens
        │  ↓
        │
        └─ DONE: Memories loaded for context
```

## Quick Decision Tree: What to Do?

```
Status: 🟢 GREEN (< 60%)
├─ Continue normally
├─ No changes needed
└─ Check daily if needed

Status: 🟡 YELLOW (60-75%)
├─ Monitor usage
├─ Consider switching to Balanced mode
├─ Start new conversation if possible
└─ Check hourly

Status: 🟠 ORANGE (75-85%)
├─ Switch to Balanced or Aggressive mode
├─ Disable memory features if not needed
├─ Reduce context window
├─ Start new conversations
└─ Check every 30 minutes

Status: 🔴 RED (85-95%)
├─ Switch to Aggressive mode (automatic)
├─ Disable all optional features
├─ Use minimal context (30%)
├─ Avoid new conversations
└─ Check every 15 minutes

Status: 🔴 BLOCKED (95%+)
├─ STOP all conversations
├─ Wait for daily reset (midnight UTC)
├─ OR increase daily limit manually
└─ Expected reset: ~8 hours
```
