## 🎯 How to Use

### Connect Claude Max in Web UI
1. Settings → **External** tab
2. Click **"🔑 Connect / Re-login"** button
3. Modal opens with OAuth component
4. Click **"Open Claude Authorization Page"**
5. Login and authorize at claude.ai
6. Copy the callback URL
7. Paste into the modal field
8. Click **"Complete Login"**

### Check Token Status
- Settings modal shows: ✅ Connected + hours remaining
- Or GET request: `curl http://localhost:50002/claude_oauth`

### Refresh Token Manually
- Click **"🔄 Refresh Token"** button in settings
- Or POST: `curl -X POST http://localhost:50002/claude_oauth -d '{"action":"refresh"}'`

### Re-login (Token Expired)
- Click **"🔑 Connect / Re-login"** button again
- Follow the authorization flow steps

## 🔄 Automatic Token Refresh Flow

```
API Call with InnovateHub
    ↓
Check token validity
    ↓
Token expired? → YES → Attempt refresh → Update .env
    ↓ NO
Make API call with valid token
    ↓
Success or error response
```

## 🐛 Troubleshooting

### Token Shows "Expired"
- **Solution:** Click "🔄 Refresh Token" button
- **Auto:** Next API call will attempt refresh

### Refresh Fails
- **Solution:** Click "🔑 Connect / Re-login"
- **Reason:** Refresh token may be invalid or revoked

### "No InnovateHub API key found"
- **Solution:** Complete OAuth setup or set API_KEY_ANTHROPIC env var
- **Check:** `echo $API_KEY_ANTHROPIC` should show token

### Modal Not Opening
- **Solution:** Reload settings page or refresh browser
- **Check:** Browser console for errors
